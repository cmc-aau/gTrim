Mask (.mask)

A mask of the columns kept from the input alignment. The file contains a single line with one character for each column of the input alignment: 1 if the column was kept and 0 if it was removed. A mask can be applied to an alignment with mask.

The following masks are written:

  • [prefix].pruned.mask (prune-gap): columns with a percentage of gaps less than or equal to --gap-threshold.

  • [prefix].trimmed.mask (trim): columns in the trimmed alignment, i.e. after subsampling.

  • [prefix].trimmed.filtered.mask (trim): columns that passed the filters, before subsampling.
