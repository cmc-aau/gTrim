Files

Output files are named after the input alignment. The [prefix] is the name of the input file with the .gz, .faa, .fna or .fasta extension removed, followed by a word for the command: .pruned (prune-gap), .trimmed (trim), .masked (mask) or .column_stats (column-stats). For example, trim on gtdb_r226_bac120_concatenated.faa.gz writes gtdb_r226_bac120_concatenated.trimmed.fasta.gz.
