mask

Apply a mask to an alignment, keeping only the columns marked with a 1. The mask must have one character for each column of the alignment (see Mask (.mask)). This can be used to apply the mask from trim or prune-gap to another alignment of the same columns, e.g. one with additional sequences.

Arguments

Required

-i, --alignment-file <ALIGNMENT_FILE>

File containing the multiple sequence alignment.

-m, --mask-file <MASK_FILE>

File containing the binary mask.

-o, --out-dir <OUT_DIR>

Output directory.

Optional

-t, --threads <THREADS>

Number of threads, in the range [1, 1024]. This option currently has no effect and mask uses a single thread.

Default: 1

Files output

  • [prefix].masked.fasta

  • gtrim.log

Example

Input

gtrim mask -i trim_test.faa.gz -m out_trim/trim_test.trimmed.mask -o out_mask
