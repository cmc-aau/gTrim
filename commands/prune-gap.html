prune-gap

Remove columns from an alignment in which the percentage of sequences with a gap is greater than a threshold. Gaps are the - and . characters. A column is kept if its percentage of gaps is less than or equal to --gap-threshold, so the default of 100 keeps every column.

Arguments

Required

-i, --alignment-file <ALIGNMENT_FILE>

File containing the multiple sequence alignment.

-o, --out-dir <OUT_DIR>

Output directory.

Optional

--gap-threshold <GAP_THRESHOLD>

Maximum percentage of gaps to retain a column, in the range [0, 100].

Default: 100

--max-residue-pruned <MAX_RESIDUE_PRUNED>

Maximum number of columns to prune. This option currently has no effect.

Default: 100000

-t, --threads <THREADS>

Number of threads, in the range [1, 1024].

Default: 1

Files output

  • [prefix].pruned.fasta

  • [prefix].pruned.mask

  • [prefix].pruned.tsv

  • gtrim.log

Example

Input

gtrim prune-gap -i gap_test.fna.gz -o out_gap --gap-threshold 50
