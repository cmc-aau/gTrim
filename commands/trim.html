trim

Trim a concatenated marker gene alignment, such as the bac120 or ar53 alignments used by the GTDB. Columns are removed if they are gappy, highly conserved or poorly conserved, and the same number of columns can then be randomly sampled from each marker to obtain an alignment of a desired length. This reimplements the msa_filter command of GenomeTreeTk. See How trim works for a description of the filters and the subsampling, and how trim differs from msa_filter.

By default (--msa-length 1000000), every column that passes the filters is kept and no columns are subsampled. Use --msa-length 5000 to subsample a 5,000 column alignment, as done by msa_filter by default.

Arguments

Required

-i, --alignment-file <ALIGNMENT_FILE>

File containing the concatenated marker gene alignment.

-m, --marker-info-file <MARKER_INFO_FILE>

Tab-separated file listing the markers in the order they are concatenated in the alignment (see markers_info.tsv). The marker lengths must sum to the length of the alignment.

-o, --out-dir <OUT_DIR>

Output directory.

Optional

--msa-length <MSA_LENGTH>

Desired length of the alignment after randomly subsampling the same number of columns from each marker. The smallest number of columns per marker that gives an alignment of at least this length is used. If fewer columns pass the filters, every column passing the filters is kept.

Default: 1000000

--min-perc-aa <MIN_PERC_AA>

Minimum percentage of sequences with a residue (not a gap) required to retain a column.

Default: 50

--min-consensus <MIN_CONSENSUS>

Minimum percentage of residues that must be the most common residue to retain a column (inclusive).

Default: 25

--max-consensus <MAX_CONSENSUS>

Maximum percentage of residues that can be the most common residue to retain a column (exclusive). Must be greater than --min-consensus.

Default: 95

--seed <SEED>

Seed for randomly subsampling columns. The same seed gives the same columns for any number of threads.

Default: 42

-t, --threads <THREADS>

Number of threads, in the range [1, 1024].

Default: 1

Files output

  • [prefix].trimmed.fasta

  • [prefix].trimmed.mask

  • [prefix].trimmed.filtered.mask

  • [prefix].trimmed.markers.tsv

  • [prefix].trimmed.genomes.tsv

  • gtrim.log

Input

gtrim trim -i trim_test.faa.gz -m trim_test_markers_info.tsv -o out_trim --msa-length 500 -t 4
