column-stats

Report the number and percentage of gaps and of each residue in every column of an alignment. Gaps are the - and . characters. No alignment is written.

Arguments

Required

-i, --alignment-file <ALIGNMENT_FILE>

File containing the multiple sequence alignment.

-o, --out-dir <OUT_DIR>

Output directory.

Optional

-t, --threads <THREADS>

Number of threads, in the range [1, 1024]. This option currently has no effect and column-stats uses a single thread.

Default: 1

Files output

  • [prefix].column_stats.tsv

  • gtrim.log

Example

Input

gtrim column-stats -i gap_test.fna.gz -o out_stats

Output
